NoshNote 개인정보처리방침

최종 수정일: 2026년 10월 15일

HaydenKwon(이하 “개발자”)은 NoshNote 앱(이하 “앱”)을 이용하는 분의 개인정보를 중요하게 생각합니다. 이 방침은 앱이 처리하는 정보와 그 처리 방법을 설명합니다.

1. 앱에서 저장하는 정보

식단 기록, 음식 이름과 섭취량, 식사 시간과 구분, 열량·단백질 수치, 사용자가 만든 음식 템플릿과 영양 목표는 앱 기능을 제공하기 위해 사용자의 기기 안에 저장됩니다. 앱에는 개발자 서버로 식단 정보를 전송하거나 계정·서버 동기화를 제공하는 기능이 없습니다.

2. 카메라와 영양성분표 OCR

영양성분표를 읽을 때만 카메라 권한을 사용합니다. 카메라 화면의 프레임은 Google ML Kit 문자 인식 기능으로 기기에서 처리되며, 촬영 이미지와 인식 결과를 개발자 서버로 전송하거나 앱 데이터로 저장하지 않습니다. 인식값은 사용자가 확인하고 적용해야 식단 기록에 반영됩니다.

ML Kit는 이미지와 인식 결과를 Google 서버로 보내지 않지만, 기능 안정성·성능 개선을 위해 기기 정보, 앱 정보 및 설치 단위 식별자 등을 포함한 진단·사용 지표를 Google에 전송할 수 있습니다. 모델 업데이트, 오류 수정 또는 기기 호환성 확인을 위해 Google 서버에 연결할 수도 있습니다. 이 처리는 Google의 개인정보처리방침 및 ML Kit 개인정보 안내에 따릅니다.

3. 백업 파일

사용자가 앱에서 JSON 백업 내보내기를 선택하면 식단 기록, 음식 템플릿과 목표가 사용자가 지정한 위치에 파일로 저장됩니다. 파일은 개발자에게 전송되지 않습니다. 파일을 가져오면 해당 기기의 앱 데이터가 백업 내용으로 교체됩니다. 내보낸 파일의 보관과 삭제는 사용자가 선택한 저장 위치에서 직접 관리해야 합니다.

4. 제3자 제공 및 광고

개발자는 앱에 저장된 식단·영양 정보를 외부에 판매하거나 제공하지 않습니다. 앱은 광고를 표시하지 않습니다. 단, 위에 설명한 ML Kit 진단·사용 지표는 Google에 전송될 수 있습니다.

5. 보관 기간과 삭제

앱 데이터는 사용자가 삭제하거나 앱을 제거할 때까지 기기에 보관됩니다. 식단 기록과 음식 템플릿은 앱 안에서 개별 삭제할 수 있습니다. 앱을 제거하면 앱 내부 데이터도 기기에서 삭제됩니다. 사용자가 별도로 내보낸 JSON 파일은 앱 제거 후에도 남을 수 있으므로 필요하지 않으면 직접 삭제해 주세요. 개발자는 앱 서버에 식단 기록을 보관하지 않습니다.

6. 정보 보호

앱 데이터는 Android의 앱 전용 저장 공간에 저장되며 Android 자동 백업은 사용하지 않습니다. 기기를 다른 사람과 공유하거나 JSON 백업 파일을 외부에 전달할 때에는 해당 파일에 포함된 식단 정보가 노출되지 않도록 주의해 주세요.

7. 아동의 개인정보

앱은 아동을 대상으로 설계되지 않았으며, 개발자는 아동의 개인정보를 의도적으로 수집하지 않습니다.
